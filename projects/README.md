# Project Case Studies

This folder is reserved for selected non-work projects that are ready for a public technical writeup. Exploratory work belongs in the private-first `personal-lab` repository until promoted.

A case study should briefly capture the **problem**, **approach**, **data**, **methods**, **validation**, **results**, **limitations**, and links to **source** or a **live demo** when available.

See the [project catalog](../PROJECTS.md) for the complete project registry. Existing website files in the repository root remain independent of this folder.
